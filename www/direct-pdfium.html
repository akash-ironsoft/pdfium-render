🚀 Direct Pdfium WASM Demo

Using Your Emscripten-Built Pdfium Directly (No Rust Layer)

📖 About This Demo

This demonstrates direct JavaScript access to your Emscripten-built Pdfium WASM module, without the pdfium-render Rust wrapper.

✅ Direct Pdfium WASM (This Page)

// JavaScript → C API
const doc = Module._FPDF_LoadDocument(...);
const count = Module._FPDF_GetPageCount(doc);
const page = Module._FPDF_LoadPage(doc, 0);

Pros: Direct, no middleman, you already have it
Cons: Low-level C API, manual memory management

⚙️ pdfium-render (Rust Wrapper)

// Rust → JavaScript → C API
let doc = pdfium.load_pdf(...)?;
let count = doc.pages().len();
for page in doc.pages().iter() {...}

Pros: High-level API, type safety, auto cleanup
Cons: Extra layer, complex setup
